# AdventureWorks 2017 Sales Dashboard

## Project Overview

This project uses the AdventureWorks 2017 sales dataset to analyze sales performance and present business insights through an interactive Power BI dashboard.

## Key Analysis

* Revenue, cost, and profit tracking
* Product and subcategory performance
* Revenue contribution by subcategory
* Daily and monthly revenue trends
* Year-to-date revenue analysis
* Month-over-month revenue growth
* Geographic sales analysis by country and region
* Customer and sales KPI monitoring

## Tools Used

* Microsoft Power BI
* Power Query
* DAX

## Business Objectives

* Identify high-performing and underperforming products.
* Monitor revenue, costs, and profitability.
* Evaluate monthly sales trends and growth.
* Compare sales performance across geographic regions.
* Present key business metrics in a centralized dashboard.

## Dashboard Preview

The dashboard includes KPI cards, product performance charts, revenue trend visualizations, a geographic sales map, and a monthly revenue comparison.

## Dataset

AdventureWorks is Microsoft's sample business dataset. The project uses the AdventureWorks 2017 sales data.

## Disclaimer

This is a portfolio project using sample data for educational and analytical purposes.
